# Сайт ООО «ГЕРА»

Локальный русскоязычный корпоративный сайт с админ-панелью Payload CMS. Включает отдельные страницы складского и контейнерного терминалов, автоперевозки на собственных седельных тягачах, форму нескольких услуг, заявки в PostgreSQL и редактируемый контент.

## Локальный запуск

Требуются Node.js 22.13 или новее (либо 20.18.1+ или 24+), Docker Desktop и npm. Для текущей версии Node используйте `22.23.3`.

1. Скопируйте `.env.example` в `.env` и замените `POSTGRES_PASSWORD` и `PAYLOAD_SECRET` локальными значениями. Если меняете пароль, измените его также в `DATABASE_URL`.
2. Выполните `npm install`.
3. Запустите `npm run local`. Скрипт поднимет PostgreSQL в Docker, создаст начальные страницы и фотографии, затем запустит сайт.
4. Откройте `http://localhost:3000/ru`. Админ-панель доступна на `http://localhost:3000/admin`; первый созданный пользователь становится администратором.

Остановка dev-сервера — `Ctrl+C`. Остановка базы без удаления данных — `npm run db:down`. Данные PostgreSQL остаются в Docker volume `gera-postgres-data`.

## Почтовые уведомления

Заявка сохраняется в базе, даже если SMTP не настроен. Для отправки писем заполните `SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURE`, `SMTP_USER`, `SMTP_PASSWORD` и `SMTP_FROM` в `.env`, а адрес получателя укажите в админке: **Уведомления по email**. После изменения `.env` перезапустите dev-сервер. Проверить доставку можно на `http://localhost:3000/ru/admin/email-test` после входа администратором. Ошибки видны у заявки; повторная отправка доступна по защищённому адресу `/api/admin/leads/{id}/retry` для администратора или менеджера.

## Наполнение и публикация

Начальные страницы и три фотографии складского терминала создаются командой `npm run seed`. Скрипт добавляет подтверждённые контакты, адрес склада и регистрационные сведения ООО «Гера» из карточки компании. Спорный КПП и банковские реквизиты не публикуются. Неподтверждённые тарифы, характеристики контейнерного терминала, режим работы и маршруты вводятся сотрудниками через админку после проверки. Контент работает на локали `ru`; схема подготовлена для будущего проверенного перевода на `zh-CN`, но пустые страницы на китайском не публикуются.

Публичные тарифы показываются только при статусе «опубликовано», активном периоде действия и включённом флаге публичного показа.

## Структура и команды

- `src/app/(frontend)/ru` — публичные страницы сайта.
- `src/collections` и `src/globals` — контент и права Payload CMS.
- `src/app/api` — приём заявок, тест почты и повторная отправка уведомлений.
- `public/images/warehouse` — оптимизированные фотографии из презентации компании.
- `ПЛАН_САЙТА.md` — исходный план проекта.

`npm run dev` запускает только Next.js, `npm run db:up` поднимает базу, `npm run seed` создаёт начальный контент, `npm run build` собирает приложение.

Юридический текст страницы обработки персональных данных — рабочий черновик. Проверить и утвердить его нужно до размещения сайта на внешнем хостинге.
